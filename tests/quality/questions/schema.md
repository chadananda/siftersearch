# Question registry schema
One JSON object per line in `questions/*.jsonl` (generated by `import.mjs`; do not hand-edit imported files, add new ones e.g. `chad.jsonl`).
`families.json` = survey taxonomy `{id,intent,scope,kind,traditions[],relative_frequency,hype_relevant}`.

| field | notes |
|---|---|
| id | unique, `<source>:<legacy id or hash>` |
| text | the question as asked |
| family | survey family id or null |
| type | router/fixture type (family kind for survey, category/type for fixtures) |
| traditions[] | bahai judaism buddhism islam christianity hinduism zoroastrianism taoism confucianism sikhism jainism |
| lang | en fa ar ... |
| scope | tradition (1 tradition) / cross (>=2 listed) / universal (none) |
| origin | survey log seo seed chad perplexity-miss regression |
| source_url | survey: where the wording was seen; null + `invented:true` = made up |
| expect | optional `{docs[], text_contains[], author, original_lang, max_rank, extra{}}`; unmapped legacy fields live in `extra` |
| wordings[] | frozen variants `{id,text,style,...}` |
| layers[] | search hype anis |
| legacy | `{file,id}` of the old fixture |
| inferred_traditions | true when traditions came from the family, not the wording |
