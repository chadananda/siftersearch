# tests/quality
Search/answer quality batteries (scored against independent ground truth; reports in `reports/`, histories in `*-history.json`).

- `score-types.mjs` + `search-type-fixtures.json`: per question-type pass rates on the search endpoints (one wording each).
- `score-anis-wording.mjs` + `anis-wording-fixtures.json` (FROZEN, from `gen-anis-wordings.mjs`): every fixture in 10-18 natural wordings x 11 styles through Anís (`/api/v1/anis/draft`), scored per stage (strategy, phrases, retrieval, selection, answer) with the first failing stage as cause; prints a type x style pass matrix.
  `node tests/quality/score-anis-wording.mjs [--sample 100] [--only id] [--types ..] [--styles ..] [--concurrency 6] [--mode current|research] [--tag name]`
  Default mode `current` (research:false) ~ $0.003/reply, exposes per-stage route data; `--mode research` ~ $0.045/reply. API base `API_BASE` (default `http://tower-nas:7839`; api.siftersearch.com is often unreachable from the Mac). Needs INTERNAL_API_KEY + DEPLOY_SECRET in .env-secrets.
- `anis-conversations.mjs`: Anís in real CONVERSATION (the site's discuss path, `/api/chat/stream`, one thread per conversation via stable `x-user-id` + `conversationId`). A simulated reader (Sonnet 5.5; personas seeker/skeptic/scholar/study_leader/non_native) explores a theme for N turns, each follow-up assigned a move that leans on earlier turns (reference, source, pushback, exact_quote, compare, deepen, absent). Then the thread trace (`/api/admin/anis/threads/:id`: route, strategy, search_query, history_turns, timeline, usd) and an Opus 5.5 judge over the whole transcript + per-turn sources/route: 9 conversation dimensions (1–5) and per-turn defects with the causing STAGE (gate, strategy, follow_up_context, retrieval, selection, answer, latency). Each defect is also saved as a fixture (`messages` up to that turn). Reports `reports/anis-conversations-<date>[-tag].json` + `.md`; history `anis-conversations-history.json`.
  `node tests/quality/anis-conversations.mjs [--themes suffering,tahirih] [--seeds 3,17] [--personas ..] [--n 2] [--turns 5] [--concurrency 2] [--tag name] [--plan-seed s] [--dry] [--rejudge <report.json>] [--publish [--status draft]]` — --themes and --seeds combine (themes first, personas by position); --plan-seed fixes the follow-up move plan so a before/after pair (r6-base / r6-after) runs the same moves
  ~$0.18/conversation of 5 turns (11-01 smoke: Anís $0.01, reader $0.023, judge $0.146). `--dry` lists the plan and an estimate with no calls; `--rejudge` re-scores saved transcripts; `--publish` (off by default) saves to published_conversations via `/api/v1/admin/conversations/save` with the thread's conversation_id. Supersedes `scripts/gen-dialogs.mjs`.
