What a strategy is

WHAT A strategy is a small decision tree for one type of request: shared tools, in tiers, cheapest first, ending in one step: choose the answer's format, then write. WHY Most questions can be answered by code and fast tools in under a second; the expensive research agent should be the fallback, not the default.

  • Jev, a fast classifier (about 50 ms), reads each message with its thread and names its type: a lead type and any others. Jev also makes the small yes/no decisions inside a strategy (found? enough? which person?).
  • Tiers. Tier 1 uses only code, tools and Jev. A tier adds a light LLM step only when code cannot do the job, and only after the cheaper tier failed. If every tier fails, the research agent takes the question.
  • One writing step. The writing model writes once, from the evidence and the chosen format. Lookups (find a book, trace a quote, a reference) need no writer: a template lays out the answer.
  • Switched on only when it matches the agent. Each strategy is measured on fresh questions of its type, with Immerse's 61 held out, against the agent's answers and Perplexity's. It goes live for its type only when it matches or beats the agent within its target time. Until then the agent answers.
  • Grounding. Counts come from 12,808 real test messages labelled by type (lead · also). Strong ≥ 100, moderate 20–99, few 3–19, thin < 3 (needs questions). The labels are a first pass, not checked gold.

The rule for combining. Jev names the lead type and the others in one classification.

  • The lead sets the answer's shape; the others add steps to the plan, not separate answers.
  • Independent steps run in parallel; a premise check (E2) or name resolution (B5) runs first because the rest depends on it.
  • The writing model gets everything found and writes once, so nothing is said twice.
  • Each common set is logged and judged as its own strategy; a combination that keeps losing gets its own tree.

Every example is a real test message from that set. Each count is one exact set of types (lead and others, any order).

The same words can be either kind of message. “What about Islam?” after an answer on fasting is a comparison follow-up; as a first message it is a new question. “The second one” means nothing without the last reply. So every message is read together with its thread before it is classified.
